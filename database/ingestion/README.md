# Data Ingestion

Use this area for data files that are being prepared for import into D1-backed domains.

## Layout

- `roots/` - Arabic root source dumps, staging files, and generated root SQL outputs.
- `morphology/` - QUL morphology source files, staging files, and generated morphology outputs.

Keep raw downloaded files under `sources/`, intermediate transforms under `staging/`, and generated SQL/JSON under `outputs/`.
