# Seed SQL

Generated SQL seed files that are applied with `wrangler d1 execute` belong here.

Current generators:

- `scripts/seed-docs.mjs` writes `seed-docs.sql` and `seed-wiki-docs.sql`.
- `scripts/gen-quran-text-seed.js` writes Quran text and metadata seed files.
- `scripts/seed-ar-quran-synonyms.mjs` writes `seed-ar_quran_synonyms.sql`.
- `scripts/export_quran_words_by_ayah.py` writes `seed-ar_quran_ayah_words.sql`.
