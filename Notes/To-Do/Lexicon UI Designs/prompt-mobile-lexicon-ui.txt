LexiconRootPageComponent

It holds the state:

Default selected source:

- otherwise first source

Pseudo:

selectedSource = computed(() => {
  const sources = payload()?.sources ?? [];
  const selected = selectedSourceSlug();

  if (selected) {
    return sources.find(s => s.slug === selected) ?? sources[0] ?? null;
  }

  return sources.find(s => s.slug.includes('raghib'))
      ?? sources[0]
      ?? null;
});

onSourceSelected(slug: string) {
  selectedSourceSlug.set(slug);
  readerTab.set('summary');
}

SECTION 1 — ROOT HERO
====================================================

Component:

LexiconRootHeroComponent

Input:
- root

Render:
- back arrow
- small title: العمل على الجذر
- optional share icon
- large root: root.text_ar
- root letters: ك · ت · ب
- Quran frequency badge
- root type badge

Data mapping:
- root title = payload.root.text_ar
- letters = parseRootLetters(payload.root.letters, payload.root.text_ar)
- frequency badge = payload.root.frequency_quran
- type badge = payload.root.type + payload.root.weak_pattern

Helper:

parseRootLetters(value: string | null, fallbackRoot: string): string[]

Rules:
- If value is JSON array string like "[\"ك\", \"ت\", \"ب\"]", parse it.
- If value is plain Arabic text, split characters.
- If null, fallback to fallbackRoot.
- Render joined with " · ".

Type mapping:
trilateral -> ثلاثي
quadriliteral -> رباعي
sound -> صحيح
weak -> معتل
hollow -> أجوف
defective -> ناقص
assimilated -> مثال
doubled -> مضعّف

Examples:
- frequency_quran = 319 -> "319× في القرآن"
- type = trilateral and weak_pattern = sound -> "ثلاثي صحيح"
